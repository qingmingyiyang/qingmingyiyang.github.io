# 见见面 · 公开体验版

从个人影像记录原型的日期、照片/视频、地点、备注和备份流程整理而来。熊帝权提出需求和产品取舍，代码与 AI 协作实现。示例文字均为虚构，配图为此次制作的 SVG 插画；不包含原作者的私人相册数据。

用静态 HTTP 服务打开 index.html。无第三方脚本、字体和模型调用。个人记录与媒体保存在独立的 IndexedDB 数据库中，不读取原型 localStorage，也不会上传。浏览器存储可能被清理，请及时备份。导入只支持本体验版的 JSON 格式，不兼容旧版 ZIP 和文件夹存储。

- 日期选择、最近记录、照片放大、视频播放、文字与地点编辑。
- 每天最多 30 个影像；单个 15 MB、总计 30 MB；最多 500 天 / 300 个影像。
- 文件保存完成后再显示成功；备份合并前校验，重复日期需确认替换。取消或校验失败不会写入。
- 首页 iframe 使用 embed=1，只浏览示例，不能访问个人记录；完整页面提供个人记录与备份。
- 浏览器能否播放视频取决于实际编码；支持的文件类型为 JPEG/PNG/WebP/GIF/MP4/WebM。

此版本是此次作品集新增的公开演示衍生稿，不等于原 Web 产品的全部功能或原 Android 开发版。原型文件保持原位。个人作品的内容和素材保留作者权利。
