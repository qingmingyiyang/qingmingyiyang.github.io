# Context Card · 上下文卡片

一个零依赖的浏览器小工具。把来源、原文、事实、判断、待验证问题和 AI 任务整理为 Markdown。

本次个人主页建设中，根据熊帝权提出的知识归档与 AI 使用需求制作，代码由 AI 协作实现。是新建的最小演示工具，与旧 Chriptmas OS 工程独立；不代表旧系统已完成重构。

## 使用

直接打开 index.html，填写标题和原文，生成、复制或下载卡片。也可用静态服务器启动。无须 API Key；不调用模型、不自动提取、不检索，也不自动上传或持久化输入。

core.js 只负责文本格式化与文件名处理；app.js 管理页面交互；index.html 组织表单。网站样式引用 ../../style.css，独立发布时请一同提供父级样式或替换成自己的 CSS。

## 边界

- 离开页面前下载；刷新后填写内容会丢失。
- 原文以引用块输出，内容不会作为 HTML 执行。
- 卡片只是组织上下文的方法，不能保证模型遵守它，也不构成提示注入防护。
- 没有用户规模、检索质量或真实模型效果评估。
