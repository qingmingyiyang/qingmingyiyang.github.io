# 熊帝权的个人主页

[公开主页](https://qingmingyiyang.github.io/) · [源码仓库](https://github.com/qingmingyiyang/qingmingyiyang.github.io)

这是面向面试阅读的个人作品集。首页从腾讯业务工具、个人知识与Agent工作台、研究与个人应用三方面展开，展示需求、规则、实际产物和修改过程。产业调研作为产品判断的来源，不改写为AI科研。

## 页面与内容

- 首页：`index.html`；暖白和深绿配色，项目截图展开呈现。
- 样式：`journey.css`；`journey.js`处理工作台范围、研究案例切换及阅读位置。
- 共用交互：`showcase.js`处理角色示例、图片放大和相册嵌入高度；`showcase.css`为旧版样式，当前首页不加载。
- 博客：`blog/`中的5篇文章，同时维护HTML和Markdown。新文章`research-to-product`讲述两次实际调研中的假设修正与产品方案调整。
- 上下文卡片：`tools/context-card/`，手动填写资料后生成可复制、下载的Markdown，没有自动提取、检索或模型调用。
- 见见面：`tools/meeting-memories/`，按日期保存和浏览影像、地点与备注，支持当前浏览器本地保存、JSON备份与确认导入。

使用静态HTTP服务预览，修改文件后刷新即可。项目无构建依赖和统计脚本；主要案例与图片不依赖JavaScript，角色及标签切换等交互需要JavaScript。

首页使用本人指定的借助AI、打造工具作为主标题。文案参考本人的语气，直接说明动作，减少解释性铺陈。需求、规则和取舍由本人提出，代码主要由AI协作实现，再通过试用继续修改。AI Native相关思考写在具体项目与协作方式中，不设置独立思考区。`#ai-native`保留为已有链接的兼容锚点。

## 截图和演示范围

`assets/projects/`有6张截图。Chriptmas OS的3张来自2026.09原型作品集，展示工作台、资料整理和项目视图，不能作为完整Agent流程达标的证据。见见面的3张来自本站公开体验版，回忆内容与插画都是示例。

角色切换使用虚构教学场景，未连接腾讯题库和真实模型。研究案例切换来自本人实际项目：粮食项目扩大访谈后修正口感假设，禽类项目根据文化诉求调整产品组合；公开内容做了匿名概述，没有相应产品的经营结果数据。

Chriptmas整体Agent目标尚未完成，资料提取、保存和找回是下一步验证范围。见见面与回响世界由AI协作开发，不意味着它们运行时已经接入大模型。见见面公开版不读取旧版存储，不兼容旧版ZIP。
